# 代码与补充材料说明

## 一、代码提交方式

- [ ] 提交 `src/` 源码目录
- [x] 提交 `05_代码仓库链接.txt`
- [x] 同时提交仓库内代码与报告目录

本项目以 GitHub 仓库方式提交代码。仓库内已包含后端、前端、Agent、RAG、测试、部署和样例材料。提交时不应包含 `.env`、本地数据库、上传文件、`node_modules`、构建产物或任何 API Key、账号密码、私有 Token。

## 二、代码目录结构

```text
fudan-pager-check/
+-- apps/
|   +-- api/              # FastAPI 后端接口
|   +-- worker/           # 异步任务与 PDF 转换任务
|   +-- web-next/         # Next.js 前端
|   +-- web/              # 旧版静态前端
+-- packages/
|   +-- agents/           # Agent 实现
|   +-- checks/           # 规则检查器
|   +-- orchestrator/     # 检查编排、进度、预览、导出
|   +-- parser/           # 双源解析与 span 构建
|   +-- rag/              # 规范库 RAG-1 与论文上下文 RAG-2
|   +-- rule_bases/       # 规范库加载服务
|   +-- schema/           # 数据模型
|   +-- storage/          # 用户、任务、决策存储
+-- config/
|   +-- journals/         # 学校/期刊规范 YAML
|   +-- rules/            # GB/T 7714 等规则 Markdown
+-- deploy/               # 生产部署与 HTTPS 配置说明
+-- docker/               # Maker/MinerU 示例镜像入口
+-- docs/plans/           # 后端、Agent、RAG、微调计划
+-- samples/              # 样例论文解析结果与测试材料
+-- tests/                # 单元测试和集成测试

+-- README.md             # 项目说明与快速启动
+-- pyproject.toml        # Python 项目依赖
+-- docker-compose.yml    # 本地 Compose 启动配置
```

## 三、核心文件说明

| 文件或目录 | 作用 | 说明 |
|---|---|---|
| `apps/api/main.py` | FastAPI 入口 | 注册认证、上传、检测、结果、进度、决策、导出等路由 |
| `apps/api/routes/check.py` | 检测提交 API | 提供 `/v1/check` 上传入口 |

| `apps/worker/tasks.py` | 异步任务入口 | 执行 PDF 转换、双源解析、span 构建、RAG-2 索引和 Agent 检查 |

| `packages/orchestrator/agent_runner.py` | Agent 编排 | 根据 `AGENT_MODE` 调度规则检查和 Agent 检查 |
| `packages/orchestrator/runner.py` | 规则检查编排 | 生成基础 CheckReport 和 Markdown 报告 |

| `packages/orchestrator/export_doc.py` | 文档导出 | 生成 docx/pdf 文件 |
| `packages/agents/*.py` | Agent 模块 | 格式、结构、引用、错别字、语法、逻辑和润色 Agent |

| `packages/rag/doc_index.py` | RAG-2 索引构建 | 为当前论文任务建立 span 上下文索引 |
| `packages/rag/doc_retriever.py` | RAG-2 检索 | 为 Agent 返回相邻 span、章节和引用上下文 |
| `config/journals/*.yaml` | 规范配置 | 通用、复旦、复旦学位论文、华南理工学报等规则 |
| `config/rules/gbt7714.md` | 参考文献规则 | GB/T 7714 参考文献规则摘录 |

## 四、运行入口

### 1. 后端 API

```bash
python3 -m pip install pydantic pyyaml httpx fastapi "uvicorn[standard]" python-multipart arq redis eval_type_backport pyjwt python-docx reportlab docker pytest
export PYTHONPATH=packages:apps
python3 -m uvicorn api.main:app --reload --app-dir apps
```

后端默认运行在 `http://localhost:8000`。健康检查：

```bash
curl http://localhost:8000/health
```

### 2. Next.js 前端

```bash
cd apps/web-next
cp .env.local.example .env.local
npm install
npm run dev
```

前端默认运行在 `http://localhost:3000`。

### 3. Docker Compose

```bash
docker compose up --build
```

### 4. 测试

```bash
PYTHONPATH=packages:apps python3 -m pytest
```

## 五、关键环境变量

| 环境变量 | 说明 |
|---|---|
| `PYTHONPATH=packages:apps` | 让 Python 能加载 `packages/` 和 `apps/` 下的模块 |
| `AGENT_MODE=rules|agents|hybrid` | 控制规则模式、Agent 模式或混合模式 |
| `OPENAI_API_KEY` | 可选，大模型调用密钥；提交材料中不要填写真实值 |
| `LLM_MODEL` | 可选，大模型名称 |
| `PDF_CONVERTER_MODE=docker` | 启用 Docker PDF 转换器 |
| `MAKER_IMAGE` | Maker 兼容镜像名称 |
| `MINERU_IMAGE` | MinerU 兼容镜像名称，可选 |
| `JWT_SECRET` | 生产 JWT 密钥；不可提交真实值 |
| `CORS_ORIGINS` | 允许访问 API 的前端来源 |
